# 아바타 기능 개선 사항

## ✅ 현재 구현된 기능
- 기본 아바타 선택 (로컬 asset 사용)
- 커스텀 아바타 업로드 (Firebase Storage)
- 아바타 표시 (홈, 상세 페이지, 댓글)
- 현재 사용자의 경우 실시간 프로필 아바타 표시
- 프로필 캐싱 (1분)

---

## 🔧 개선이 필요한 사항

### 1. **마이페이지에 아바타 표시** ⚠️ 중요도: 중
**현재 상태**: `app/me/index.tsx`에 아바타 표시 없음

**개선 방안**:
- 마이페이지 상단에 프로필 카드 추가
- 아바타, 닉네임, 통계 표시
- 설정으로 이동하는 버튼

**예상 작업 시간**: 30분

---

### 2. **아바타 삭제 기능** ⚠️ 중요도: 중
**현재 상태**: 아바타를 제거하거나 기본 아바타로 리셋하는 기능 없음

**개선 방안**:
- 설정 화면에 "아바타 제거" 버튼 추가
- 제거 시 `avatarUrl: null`로 설정
- 기본 아바타로 변경하는 옵션도 제공

**예상 작업 시간**: 20분

---

### 3. **Firebase Storage 이미지 삭제** ⚠️ 중요도: 높음
**현재 상태**: 아바타 변경 시 기존 Firebase Storage 이미지가 삭제되지 않음 → 저장 공간 낭비

**개선 방안**:
- 아바타 변경 전 기존 이미지 URL 확인
- Firebase Storage에서 기존 이미지 삭제
- `deleteObject` 함수 추가

**예상 작업 시간**: 30분

**코드 위치**: `src/lib/storage.ts`에 `deleteImage` 함수 추가 필요

---

### 4. **이미지 리사이징/압축** ⚠️ 중요도: 높음
**현재 상태**: 원본 이미지 그대로 업로드 → 큰 파일 크기, 비용 증가

**개선 방안**:
- `expo-image-manipulator` 사용하여 리사이징
- 아바타는 최대 400x400px로 제한
- JPEG 품질 80%로 압축

**예상 작업 시간**: 1시간

**필요 패키지**: `expo-image-manipulator`

---

### 5. **프로필 실시간 구독** ⚠️ 중요도: 낮음
**현재 상태**: 수동 캐시 무효화 방식

**개선 방안**:
- `Avatar` 컴포넌트에서 현재 사용자 프로필 실시간 구독
- `onSnapshot`으로 프로필 변경 감지
- 캐시 대신 실시간 업데이트

**예상 작업 시간**: 1시간

**장점**: 아바타 변경 시 즉시 반영
**단점**: 추가 Firestore 읽기 비용

---

### 6. **에러 처리 개선** ⚠️ 중요도: 중
**현재 상태**: 기본적인 에러 처리만 있음

**개선 방안**:
- 네트워크 오류 시 재시도 로직
- 이미지 로드 실패 시 fallback 이미지
- 사용자 친화적인 에러 메시지

**예상 작업 시간**: 30분

---

### 7. **아바타 표시 위치 확인** ⚠️ 중요도: 낮음
**확인 필요**:
- `app/me/posts.tsx` - 내 게시물 목록
- `app/me/comments.tsx` - 내 댓글 목록
- `app/explore.tsx` - 탐색 화면

**예상 작업 시간**: 30분

---

### 8. **아바타 업로드 진행률 표시** ⚠️ 중요도: 낮음
**현재 상태**: 업로드 중 상태만 표시

**개선 방안**:
- 업로드 진행률 표시 (ProgressBar)
- 큰 이미지 업로드 시 사용자 경험 개선

**예상 작업 시간**: 30분

---

## 📊 우선순위 정리

### 높은 우선순위 (즉시 개선 권장)
1. **Firebase Storage 이미지 삭제** - 비용 절감
2. **이미지 리사이징/압축** - 비용 절감 및 성능 개선

### 중간 우선순위 (개선 권장)
3. **아바타 삭제 기능** - 사용자 편의성
4. **마이페이지에 아바타 표시** - UI 완성도
5. **에러 처리 개선** - 안정성

### 낮은 우선순위 (선택 사항)
6. **프로필 실시간 구독** - 성능 vs 실시간성 트레이드오프
7. **아바타 표시 위치 확인** - 누락된 위치 확인
8. **업로드 진행률 표시** - UX 개선
