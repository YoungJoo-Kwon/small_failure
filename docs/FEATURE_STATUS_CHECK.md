## 1️⃣ 홈 화면 (피드 & 갤러리)

### 목표 기능
- ✅ 카드형 게시물: 실패 상황 + 교훈 요약
- ❌ 라이트 모드: "짧은 실패 글 + 교훈 한 줄" → SNS보다 부담 없음
- ❌ 프로 모드: 제목/본문/교훈/태그가 구조화된 형태
- ❌ 상단 토글: 🔘 "짧게 보기" ↔ 🔘 "자세히 보기"

### 현재 구현 상태

#### ✅ 구현됨
1. **카드형 게시물 표시**
   - 위치: `app/index.tsx:173-205`
   - 카드 형태로 게시물 리스트 표시
   - 제목, 작성자, 작성일, 공감/댓글/붙이기 수 표시

2. **정렬 기능**
   - 위치: `app/index.tsx:92-123`
   - 최신순/공감순 토글 구현됨 ✅
   - 실시간 정렬 동작

#### ⚠️ 부분 구현
1. **PostItem 컴포넌트**
   - 위치: `src/components/PostItem.tsx`
   - `light` / `detailed` 모드 모두 구현되어 있음
   - **문제**: 실제 피드에서 사용되지 않음
   - 현재 `app/index.tsx`는 직접 카드 렌더링 (PostItem 미사용)

#### ❌ 미구현
1. **라이트/프로 모드 토글**
   - `ModeToggle` 컴포넌트는 존재 (`src/components/common/ModeToggle.tsx`)
   - 하지만 `app/index.tsx:6`에서 주석 처리되어 비활성화됨
   - 피드에서 모드 전환 기능 없음

2. **교훈 한 줄 미리보기**
   - 피드에서는 제목만 표시, 교훈 표시 안 됨

### 구현률: **60%**

**개선 필요 사항**:
- [ ] `PostItem` 컴포넌트를 피드에서 사용하도록 변경
- [ ] `ModeToggle`을 다시 활성화하여 라이트/프로 모드 전환 기능 추가
- [ ] 피드에 교훈 한 줄 미리보기 추가

## 2️⃣ 글 작성 플로우

### 목표 기능
- ✅ 공통: 실패 기록 → 교훈 한 줄 → 태그 추가
- ⚠️ 대학생 라이트 모드: "시험 망쳤다 😭" → "교훈: 벼락치기는 역시 안 된다"
- ⚠️ 직장인 프로 모드: 제목/본문/교훈/태그 구조화 기록 → 보관/공유 선택

### 현재 구현 상태

#### ✅ 구현됨
1. **글 작성 폼**
   - 위치: `app/new.tsx`
   - 제목 입력 (한 줄 요약)
   - 본문 입력 (상세 설명)
   - 교훈 입력 (핵심 교훈)
   - 태그 추가 (쉼표 구분 + 추천 태그)

2. **이미지 업로드**
   - 위치: `app/new.tsx:23-28, 155-193`
   - 이미지 선택 기능 구현 ✅
   - Firebase Storage 업로드 구현 ✅

3. **기본 필드 검증**
   - 제목/본문/교훈 필수 검증

#### ⚠️ 부분 구현
1. **라이트/프로 모드 구분 없음**
   - 현재 단일 작성 폼만 존재
   - 라이트 모드 (짧은 글)와 프로 모드 (상세 글) 구분 없음
   - 단일 폼으로 모든 유형 처리

2. **보관/공유 선택**
   - 공유만 가능, 비공개 보관 옵션 없음

### 구현률: **80%**

**개선 필요 사항**:
- [ ] 라이트/프로 모드 선택 UI 추가
- [ ] 비공개 저장 옵션 추가 (status: "hidden" 활용)
- [ ] 라이트 모드 시 간소화된 입력 폼 제공

## 3️⃣ 소통 기능

### 목표 기능
- ⚠️ 공감 버튼: 👍 "나도", 🤝 "위로", 🔥 "힘내자"
- ✅ 실패 붙이기 기능: 다양한 실패담을 서로 연결해 연관 실패를 제공
- ✅ 짧은 댓글: "나도 이런 적 있음 ㅠㅠ", "좋은 팁이네!"
- ❌ 비슷한 실패 추천: 태그 기반으로 유사 경험 연결

### 현재 구현 상태

#### ✅ 구현됨
1. **공감 기능 (기본)**
   - 위치: `app/post/[id].tsx:126-134`, `src/lib/posts.ts:228-252`
   - `toggleLikeRobust` 함수로 중복 방지된 공감 구현
   - 서브컬렉션 + 트랜잭션 기반 안정적 구현
   - **문제**: UI에서 공감 상태 표시 안 됨

2. **실패 붙이기 기능**
   - 위치: `app/post/[id].tsx:151-175`, `src/components/attach/AttachModal.tsx`
   - 다른 실패담을 현재 글에 연결하는 기능 ✅
   - 내 글 검색, 제목 검색, URL/ID 붙여넣기 지원 ✅
   - 연결된 실패담 미리보기 표시 ✅

3. **댓글 기능**
   - 위치: `app/post/[id].tsx:262-299`
   - 텍스트 댓글 작성/표시 ✅
   - 실시간 댓글 목록 표시 ✅

#### ⚠️ 부분 구현
1. **공감 버튼 UI**
   - 단순 "공감" 버튼만 있음
   - 목표했던 "나도", "위로", "힘내자" 등 세 가지 감정 버튼 없음
   - 내가 공감했는지 시각적 표시 없음
   - `listenMyLike` 함수는 있지만 UI에서 사용 안 함

2. **댓글 기능**
   - 기본 댓글만 지원
   - "짧은 댓글" 강조 없음

#### ❌ 미구현
1. **비슷한 실패 추천**
   - 태그 기반 추천 기능 없음
   - `searchByTag` 함수는 있지만 UI에서 활용 안 됨
   - 관련 실패담 추천 섹션 없음

### 구현률: **70%**

**개선 필요 사항**:
- [ ] 공감 버튼을 3가지 감정으로 확장 (나도/위로/힘내자)
- [ ] 공감 상태 UI 표시 (`listenMyLike` 활용)
- [ ] 태그 기반 유사 실패담 추천 섹션 추가
- [ ] 댓글 UI 간소화 (짧은 댓글 강조)

## 4️⃣ 성장 연결 기능

### 목표 기능
- ❌ 글을 자동 시리즈로 묶음 → "시험 실패 시리즈", "프로젝트 관리 시리즈"
- ❌ 마이페이지에서 실패 → 교훈 → 개선 타임라인 제공
- ❌ 교훈만 모은 "한 줄 성장 노트" 탭 제공
- ❌ 그래프/통계: "실패 횟수 vs 개선 포인트" 시각화

### 현재 구현 상태

#### ✅ 구현됨
1. **마이페이지 기본**
   - 위치: `app/me/index.tsx`, `app/me/posts.tsx`
   - 내 글 목록 조회 ✅
   - 내 댓글 목록 조회 ✅

#### ❌ 미구현 (모두)
1. **시리즈 기능**
   - 자동 시리즈 묶기 없음
   - 태그나 주제 기반 그룹핑 없음

2. **타임라인 기능**
   - 실패 → 교훈 → 개선 타임라인 없음
   - 시간 순서 정렬만 있을 뿐 성장 시각화 없음

3. **교훈 노트**
   - 교훈만 모은 탭 없음
   - 내 글에서 교훈 추출 기능 없음

4. **통계/그래프**
   - 통계 시각화 없음
   - 실패 횟수, 개선 포인트 추적 없음

### 구현률: **20%**

**개선 필요 사항**:
- [ ] 태그/주제 기반 자동 시리즈 그룹핑 기능
- [ ] 마이페이지에 타임라인 뷰 추가
- [ ] "한 줄 성장 노트" 탭 구현 (교훈만 추출)
- [ ] 통계 그래프 컴포넌트 추가 (차트 라이브러리 필요)
