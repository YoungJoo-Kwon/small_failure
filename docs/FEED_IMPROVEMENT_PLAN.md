- 초기 설계 목표와 불일치

- PostItem의 detailed 모드가 활용되지 않음

```typescript
- 두 토글을 가로로 배치
- 반응형으로 작은 화면에서는 세로 배치
```

##### 대안 2: 드롭다운 메뉴
```typescript

// 단점: 접근성 낮음

```

##### 대안 3: 설정에 저장
```typescript
// 장점: 영구 저장, 사용자별 맞춤
// 단점: 즉시 전환 불가

- 설정 화면에서 변경
```

**권장 구현**: 대안 1 (간단한 토글 버튼)
- 구현 난이도: 낮음

#### 2. PostItem 모드 prop 전달
**현재 상태**:
- ⚠️ PostItem 컴포넌트는 mode prop을 받지만 피드에서 전달하지 않음
- ⚠️ 항상 기본값 'light' 모드만 사용

**문제점**:
- detailed 모드가 구현되어 있으나 사용되지 않음
- 코드 중복 (PostItem의 기능 미활용)

**대안 제안**:

##### 대안 1: 상태 기반 모드 전달 (권장 ⭐)
```typescript
const [viewMode, setViewMode] = useState<'light' | 'detailed'>('light');

<PostItem post={item} mode={viewMode} />
```

##### 대안 2: 설정 기반 모드
```typescript
const { viewMode } = useSettings(); // SettingsContext에 추가

<PostItem post={item} mode={viewMode} />
```

**권장 구현**: 대안 1 (상태 기반)
- 즉시 반응
- 구현 간단
- 사용자 선호도 저장은 추후 추가 가능
