   ```typescript
     "살고 싶지 않다", "죽고 싶다", "자살",
     "공황", "우울", "절망"
   ];
   ```

   - `UserSettings`에 `careAlert`, `careTone` 필드 추가
   - `SettingsContext`에 케어 설정 추가

   ```typescript

     return DANGEROUS_KEYWORDS.some(keyword => 
       text.includes(keyword)
     );
   };
   ```
