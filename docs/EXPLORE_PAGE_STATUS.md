## 🔍 기술적 세부사항

### 사용된 Firestore 쿼리

1. **제목 prefix 검색** (`searchPostsByTitlePrefix`)
   ```typescript
   query(
     collection(db, "posts"),
     where("titleLower", ">=", key),
     where("titleLower", "<=", end),
     orderBy("titleLower"),
     limit(20)
   )
   ```
   - **필요 인덱스**: `posts(titleLower ASC)`

2. **태그 검색** (`searchByTag`)
   ```typescript
   query(
     collection(db, "posts"),
     where("tags", "array-contains", tag),
     orderBy("createdAt", "desc"),
     limit(20)
   )
   ```
   - **필요 인덱스**: `posts(tags ASC, createdAt DESC)`

- ✅ 컴포넌트 언마운트 시 구독 해제
- ✅ 검색 변경 시 이전 구독 정리

### 상태 관리
